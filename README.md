# make-knowledge-cards

`make-knowledge-cards` 是一个 Codex Skill，用于把用户粘贴的文章或本地 Markdown/TXT 文件整理成简洁、可复习的知识卡片。

## 解决什么问题

长文章往往包含重复表述、背景信息和多个混杂主题，阅读后不容易抓住重点。本 Skill 从原文中选出真正重要且彼此独立的知识点，压缩为结构统一的卡片，便于理解和复习。

它只依据输入内容生成结果：不补造原文没有的事实、原因、例子、数字或结论；当原文信息不足时，也不会为了凑数强行输出 5～8 张卡片。

## 主要功能

- 接收直接粘贴的文章，或本地 `.md`、`.markdown`、`.txt` 文件。
- 提炼重要的概念、主张、机制、区别、流程或决策规则。
- 一张卡片只讲一个知识点，合并同义重复内容。
- 每张卡片包含标题、核心知识、简明解释，以及原文例子或自测问题。
- 原文内容足够时，通常输出 5～8 张卡片；否则按实际信息量减少输出。

暂不支持网页抓取、PDF、Anki 导出和图形界面。

## 安装方法

将本仓库中的 Skill 目录复制到 Codex 的 Skills 目录：

```text
<Codex Skills 目录>/make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

本项目中的对应目录是：

```text
skills/make-knowledge-cards
```

重启或刷新 Codex 的 Skill 列表后，即可通过 `$make-knowledge-cards` 调用。

## 使用方法

```text
使用 $make-knowledge-cards 将下面的文章转换成知识卡片：
<粘贴文章内容>
```

处理本地文本文件：

```text
使用 $make-knowledge-cards 将本地文件 C:\资料\文章.md 转换成知识卡片。
```

## 输入输出示例

输入：

```text
番茄工作法把工作分成 25 分钟的专注时段，每个时段后短暂休息。完成四个时段后可安排较长休息。它的重点是用明确的边界降低分心。
```

输出：

```markdown
## 卡片 1：专注时段与休息
- 核心知识：番茄工作法以 25 分钟专注时段和其后的短暂休息组织工作。
- 简明解释：它将工作与休息交替安排，形成清晰的时间边界。
- 例子或自测：一个专注时段结束后应安排什么？

## 卡片 2：较长休息的安排
- 核心知识：完成四个专注时段后可安排较长休息。
- 简明解释：较长休息出现在四个时段完成之后，而不是每个时段之后。
- 例子或自测：较长休息在完成几个专注时段后安排？
```
